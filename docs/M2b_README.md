# M2b · 第一关完整体验

本阶段将主菜单“开始冒险”升级为第一关 **苔光遗庭 / Mosslight Gardens**。教学与训练营仍独立可用。第一关结束时结算并三选一奖励；第 2～6 关、商店和入口检查点属于 M3/M4，不把它们描述为已实现。

## 启动

- Unity **6000.6.4f1** 打开内层 `AI_Rogue_Game` 工程（包含 Assets、Packages、ProjectSettings）。入口 **Assets/_Game/Scenes/Boot.unity**，直接 Play。
- 配置/场景已存在，无需重新生成；缺失时使用 **Starfall → Setup M2b**。初始化菜单只补缺失资源，保留现有场景和调参。
- 普通 Windows x64 输出 **Builds/M2b/StarcoreLabyrinth.exe**，保留同目录配套文件。重建菜单 **Starfall → Build M2b Windows**，不需要 Development Build。
- 设置与纪录分别保存为本机持久目录中的 `starfall-settings.json`、`starfall-records.json`，安全写入并保留 `.bak`。教学/训练不覆盖主线记录。继续入口仍明确禁用，M3 才提供检查点。

## 第一关路线

**安全入口 → 苔光庭院 → 北信标守卫厅 → 错位回廊 → 南信标守卫厅 → 脉冲继电室 → 队长前补给区 → 石卫队长竞技场。** 庭院另接可选限时试炼支路。

WASD 移动、鼠标瞄准、左键射击、Space 闪避、E 交互、Q 主动道具、1/2 换枪、Tab 地图、Esc 暂停。入口四个站可各领取一次霰弹枪、冲锋枪、急救包或护盾；手枪常驻，不依赖特殊装备也可推进。

四座战斗房有不同掩体布局，清场后一次性补充部分生命、能量和主动充能。信标厅必须清场后到右上方按 E 激活，才能从右侧前进；金币和特殊武器不决定主路是否开放。已清理的房间可返回，不重刷敌人或房间奖励。

脉冲继电室先出现警告横条再造成伤害；上/下方均有安全路线。两座信标激活后到右上方按 E 关闭继电器。补给区中部有一次性完整补给，可恢复生命、能量、充能和冷却。

可选支路限时 35 秒，可随时从左下返回主路。按时清场获得闪避被动；超时不发该被动并解除支路战斗，不阻断主路。支路不会通过反复中途退出刷金币掉落。

石卫队长使用 **扇形连射、预警冲锋、环形弹幕**，动作均先预警，随后执行并有恢复窗口。Boss 死亡立即停止攻击并清弹，关卡结算在帧末检查玩家存活；同帧死亡按失败处理。

## 计时与纪录

统一服务用单调时钟计时，获得操作权开始，合法完成且当帧存活时停止。探索、支路和可操作的决策时间计入；Esc、Tab 地图、失焦、暂停设置和不可操作加载扣除，重叠暂停只扣一次。Boss 奖励选择和等待点击按钮不继续计时。

HUD 显示本关时间/最佳，可在设置中隐藏 HUD 计时而不停止统计。结算向下量化到整数毫秒并统一显示 `mm:ss.fff`，分钟不限两位。失败只显示“本次挑战用时”，不参与快慢比较。

纪录按 **关卡 ID / standard 难度 / 计时规则 v1 / 平衡 v1** 分组，保留旧规则纪录供查看。个人纪录页列出六关名称、最佳时间、种子、日期、构筑和适用规则；后五关目前显示尚无纪录，没有从纪录页跳关入口。不同种子和合法构筑共享该关个人最佳，不是同图竞速。

首次完成、严格刷新、毫秒追平、接近最佳、其他通关、失败有六种独立中英文反馈；无资格通关单独显示练习成绩。调试装备、训练辅助或调速导致资格失效后，本次尝试不能恢复资格。

合法完成即保存纪录，使用尝试 ID 防重复，不等领取奖励。保存失败明确提示并保留冻结成绩，可在结算页重试；离开当前结算后仍可从纪录页重试未保存成绩，保留至本次程序关闭。保存失败不会误报成功。Boss 三选一只能领取一次，候选不重复，候选不足时用金币/治疗/能量补位。

## 设置与反馈

设置支持语言、窗口/全屏、主/音乐/音效音量、震屏强度、闪光减弱和 HUD 计时。沿用旧语言/教学标记，旧版设置有安全的音量默认值。音效和环境底音程序生成，区分射击、命中、受伤、闪避、拾取、UI、清场和 Boss；限制同时播放声音数量。音色仍为占位，待 M5 完善。

## 按顺序人工验收

1. 从主菜单开始第一关，在入口选装备，清理庭院和北厅；未清场/未激活信标时门应保持锁定。Tab 查看房间图和主路进度。
2. 从庭院进入限时支路并主动返回，或等待超时；主路应始终可继续。返回已清理房间，不应重刷敌人或奖励。
3. 激活两座信标，走过脉冲安全路线并关闭继电器，领取一次补给。再领取不能重复恢复。观察 Boss 三种预警并正常击败。
4. 结算查看本次时间、原最佳、差值和保存状态；三选一只生效一次。返回菜单查看纪录，关闭并重启确认保持。
5. 再次挑战或死亡重开。确认六种结果按实际成绩分支呈现，失败不入榜；在战斗中叠加地图/暂停/设置，解除一个原因不应提前恢复时间、机关或冷却。
6. 在战斗、地图、设置、纪录和结算中切换语言；调节音量、关闭震屏、减弱闪光并隐藏 HUD 计时。确认状态/成绩保留。退出训练再冒险，确认无辅助或装备残留。

开发验证证据保存于外层用户指定的 **appendix/M2b**。自动键鼠正常装备流程与规则注入测试分别说明，不冒充人工试玩。程序生成美术/音效仍为占位；教学节奏、人工平衡、手动窗口操作和性能目标需要人工验收，没有未测性能数字。
