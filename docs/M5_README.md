# M5：精绘美术与单关远征

本阶段依据上层 `improve.md` 实施。玩法入口改为六关自由选择；通关永久解锁装备，整备后可带入任意关。美术改为精细手绘 2D，旧像素约定由用户明确变更。

## 开始游戏

打开 `Assets/_Game/Scenes/Boot.unity`。首次选择语言，然后从“选择关卡”进入六张主题卡。点击卡片查看关卡特点、通关奖励与个人纪录，再点“开始本关”。无需先通前关，也无需每次重新整备。

普通 Windows x64 程序已生成到 `Builds/M5/StarcoreLabyrinth.exe`。直接运行；搬运时保留同目录的 `StarcoreLabyrinth_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 和其余依赖及 `Licenses`。构建通过，完成 15 秒启动检查。

“出战整备”固定携带手枪，可选择一件特殊武器、一件主动道具及六种不同被动；每种被动开局一层，局内最多两层。金币、能量与消耗次数按新的挑战初始化。死亡不删除永久装备。训练可以试用全装备，但不修改正式整备、永久解锁或正式成绩。

WASD 移动，鼠标瞄准，左键攻击，Space 闪避，1/2 切换手枪与特殊武器，Q 使用主动道具，E 拾取装备，F 操作设施/门，Tab 地图，Esc 返回/暂停。金币、治疗和能量补给为接近自动拾取。

第一关主路为庭院（包含安全门廊）→北信标→回廊→南信标及补给角→石卫队长。越过门廊才启动第一场战斗；庭院战后可打开武器箱；第二信标直接关闭脉冲并解锁首领入口。挑战支路可以退出，未领取的物品可以回头取。

## 保存与奖励

- `starfall-profile.json`：永久装备、通关状态、待选奖励、正式整备。
- `starfall-reward-journal.json`：奖励事务恢复日志；正常完成保存后删除，异常时下次启动恢复。
- `starfall-checkpoint.json`：所选关入口快照。继续从该关入口重开；通关或死亡结束本次快照。
- `starfall-records.json`：个人纪录。M5 使用 `stage_select` 分组、计时规则 2、平衡规则 3，与旧连续冒险纪录分开。
- 设置文件保留合法的音量 0、语言及教学标记。旧 `m3-v1`/`m4-v1` 入口迁移为 M5 练习资格，旧装备和金币不转换为永久所有权。

通关先原子保存固定奖励和待选资格，随后可选择一件未解锁装备；暂不领取可返回选关，之后再领。全部收集后可继续挑战。奖励保存失败时显示原因及“重试保存奖励”；不能以“已保存”假装成功。

## 正式资源与工具

美术和字体映射为 `Assets/_Game/Resources/PresentationCatalog.asset`。原始素材、图像提示词和音频源放在 Unity 项目内的 `ArtSource/M5/`；运行时资源位于 `Assets/_Game/Art/`、`UI/`、`Audio/` 和 `Data/Rendering/`。详见 [资源清单](M5/asset-guide.md)。

Unity 菜单 `Starfall/Setup M5 Presentation` 可重建稳定的 Sprite 切片、三个 TMP 字体、默认/精简后期、三组混音总线；`Validate M5 Assets` 检查引用与 25 个装备来源；`Build M5 Windows` 创建普通 Windows x64 构建。无需系统安装字体，无需网络获取资源。

`Tools/M5Audio.py` 可重建原始音频；`ArtSource/M5/Audio/analysis.json` 记录每段长度、峰值和 RMS。设置中的“测试声音”使用不受世界暂停影响的 UI 声道。实际扬声器/耳机听感请用普通构建验收。

## 验证资料

本阶段的最终测试结果、截图和普通输入报告统一保存在上层 `appendix/M5/`。`acceptance.md` 分别列出实现、自动验证和需要用户判断的实机听感/审美/节奏。截图由真实 Unity 渲染生成。

最终完整回归为 55 项规则测试、45 项运行测试；最后补充设施操作音效后另有 1 项专项复核。两种语言 × 1280×720、1920×1080、2560×1440、1280×960 的 M5 布局诊断为 0 项。软件声音探针已有非零监听器输出，硬件听感尚需实际体验。

另有通过专项验证的 51 秒第一关正常输入录像，位于上层 `appendix/M5/replay/`。打开 `index.html` 可按实际时间查看原始 Unity 帧；`first-stage-normal-input.avi` 为无声 MJPEG，未绘制或插值画面。录像夹具只属于 Editor 测试，不进入普通发布程序。
