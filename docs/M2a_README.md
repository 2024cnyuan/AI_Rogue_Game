# M2a · 教学与训练营基础

本阶段实现完整独立教学和自由训练营。开始冒险仍进入 M1 单房样板；第一关连贯流程、Boss、正式纪录与检查点属于 M2b 及后续阶段。

## 启动

1. 用 Unity **6000.6.4f1** 打开此目录 `AI_Rogue_Game`（包含 Assets、Packages、ProjectSettings），不要把外层资料目录当作 Unity 工程。
2. 打开 `Assets/_Game/Scenes/Boot.unity`，点击 Play。已有场景和配置可直接使用，无需重新生成。如缺配置，执行 **Starfall → Setup M2a**；该菜单只补充缺失资源，不覆盖已存在的场景或参数。
3. 普通 Windows x64 程序：`Builds/M2a/StarcoreLabyrinth.exe`。须保留同目录的配套数据、DLL 和运行库。首次选择语言后可开始教学或直接冒险；以后从主菜单进入教学、训练或冒险。
4. 重新构建：**Starfall → Build M2a Windows**。输出为普通构建，不依赖 Development Build 或调试面板。

## 操作与教学路线

WASD 移动，鼠标瞄准，左键连续攻击，Space 闪避，E 交互，Q 主动道具，1 手枪，2 特殊武器，Tab 地图，Esc 暂停/返回上层。

七步教学按真实行为推进：

1. 到左侧中部金色标记，瞄准左上方金色指示。
2. 命中左上两座靶。第二座被竖墙阻挡，需绕到墙右侧。
3. 中部横廊有从右向左的慢速子弹。在攻击接近时闪避，必须实际避开攻击；只按 Space 不算完成。25 秒有效游戏时间后提供加强提示和“跳过闪避步骤”。
4. 沿下方拾取金币，在下方左侧按 E 领取霰弹枪。1/2 可切换；命中上方靶，持续射击直到出现能量不足，再按 1 换回手枪。能量补给在下方路线。
5. 在下方中部按 E 领取急救包，Q 成功治疗，再在右侧两个被动站任选一个。测试条件会预先扣除部分生命，避免满血无法治疗；提示显示射击间隔或最大生命的实际变化。
6. Tab 打开并关闭地图，到右上方信标按 E 激活，然后到右侧出口按 E 通过任务门。
7. 对抗右区两名普通敌人与一名低伤害精英；全清后在出口按 E 结算。可转入冒险样板、训练营或菜单。

“重试当前步骤”及教学死亡会清理当前敌人、弹丸、交互物、目标和机关，并恢复该步骤入口装备与资源。暂停菜单“重新开始”或退出再进入会从教学起点开始。完成和跳过标记分别保存；不产生正式纪录或可带入冒险的装备奖励。

## 训练营

五个区域有名称标识。靠近青色工作站按 E，也可用底部“整备区 / 练习控制”按钮。

| 区域 | 本阶段功能 |
| --- | --- |
| 整备区 | 免费更换手枪、霰弹枪、冲锋枪，急救包/护盾，添加或移除射速、拾取范围、最大生命、闪避冷却被动。每种最多两层；保留手枪和一个特殊武器槽、一个主动槽、最多六种被动。换枪只保留一件旧武器掉落。 |
| 靶场 | 静止靶、移动靶、50% 减伤护甲靶。实时显示有效单次伤害、累计伤害、最近 10 秒有效游戏时间平均 DPS；不足 10 秒按重置后时间计算。暂停不推进窗口，换装、换枪或重置清零。 |
| 闪避跑道 | 三档强度的慢速弹幕、冲锋预警条与地面危险；手动启动和停止。关闭控制台后开始运行。 |
| 模拟战区 | 3/6/12 名追击者、射手、精英或混合组合；再次启动替换上一次敌人，最多 12 名存活敌人。可停止清场。训练敌人不堆积金币掉落。 |
| 环境体验区 | 本阶段预留区域；传送带、冰面与电网明确标注未实现，随对应正式关卡补入。 |

默认无限能量、无限主动充能、无敌，三项独立开关且持续显示。保留真实射速、主动冷却和护盾持续时间。“恢复生命 / 资源”恢复生命、能量和冷却；“重置练习”清理敌人、弹丸、掉落、机关、效果、击杀和伤害统计，保留装备与辅助选择；“恢复默认装备”另行清空构筑。关闭无敌后死亡在营地复位，不进入冒险死亡结算。

## 建议人工验收

1. 从 Boot 或普通程序进入教学，按七步走到结算。确认按键本身不能代替到达、命中和实际使用，资源不足后手枪仍可攻击。
2. 重玩教学，在闪避或综合演练中死亡/点击重试。确认保留当前步骤并恢复资源；再测试跳过、退出重入及完成/跳过标记区别。
3. 进入训练，逐一试用本阶段 9 件物品，添加被动到两层再尝试第三层；换装、移除和默认装备恢复应立即生效。
4. 射击三类靶，检查护甲减伤及实时统计。Tab、Esc 或控制台暂停后观察 DPS 与冷却冻结；启动机关和 12 名模拟敌人，停止并反复重置。
5. 单独关闭辅助并死亡。确认营地复位、装备保留、辅助仍关闭。返回菜单再开始冒险，确认无训练装备、金币、无限资源或无敌残留。
6. 在教学、装备说明、地图、暂停和结算中切换中英文，确认状态保留、立即刷新且重启后语言保存；手动检查窗口/全屏与 Alt-Tab。

## 验证和限制

权威开发验收记录与 XML/截图在外层用户指定的 `appendix/M2a/`。测试覆盖实际输入、弹丸、流程、重试和模式隔离；教学测试为定位各步骤使用位置安排，综合战斗由弹丸池驱动，不能当作人工正常通关或手感/平衡验证。正式检查点尚未实现，当前只验证练习模式不改写预置检查点文件。

现有程序生成像素形状、场景和反馈仍为占位美术；无新增音效。其余 3 武器、4 主动、8 被动在界面明确标为未实现。人工完整试玩、教学 3～5 分钟节奏、窗口交互、目标机器字体回退及性能目标待用户验收。没有提交或推送 Git。
