# M3 · 第二、第三关与入口检查点

Unity 6000.6.4f1，沿用原 Input System、URP、UGUI 与 Test Framework 版本。前三关可连续游玩；第三关结束后停在 M3。第四至第六关及其物品/机制属于 M4。

## 启动

打开内层 `AI_Rogue_Game` 工程（Assets、Packages、ProjectSettings 所在目录），打开 `Assets/_Game/Scenes/Boot.unity` 直接 Play。场景与配置随工程交付，不需要初始化。缺失资源时执行 `Starfall → Setup M3`，只补缺失配置及工坊稀有冲锋枪定义，不覆盖现有场景、物品或调参。

普通 Windows x64 输出：`Builds/M3/StarcoreLabyrinth.exe`，须保留同目录配套文件。重建菜单：`Starfall → Build M3 Windows`，使用普通构建。

WASD 移动、鼠标瞄准、左键射击、Space 闪避、E 交互、Q 主动、1/2 换枪、Tab 地图、Esc 暂停或关闭商店。每关入口、清场奖励及 Boss 前补给均支持现有真实装备规则。手枪常驻，主路不依赖购买、随机掉落或支路。

## 前三关流程

第一关保留两信标、脉冲机关和石卫队长。Boss 合法死亡即停止计时并独立保存纪录；三选一奖励领取后可进入下一关。

第二关赤铜工坊使用铜色装配区、错位掩体、右推传送带和侧道仓库。主路：入口 → 铸造前庭 → 北保险芯仓 → 传送带装配厅 → 南保险芯仓 → 过载炉控制室 → 补给 → 熔炉竞技场。前庭支路仓库连回装配厅；北芯仓另接商店。两枚保险芯在对应房清场后按 E 保证取得，进入独立任务账本，不占装备槽、不能售卖；关闭过载炉后才能进入 Boss。

工坊敌人有固定炮台、右侧可见护甲板的护盾兵和预警圆圈爆破机。炉室危险有金色预警与停歇，上下均可绕行。熔炉监工有三圈迫击炮、缓慢扫射和泄压弹环，各有预警、执行与恢复。装配厅可自愿进入额外生产线，与精英及普通敌人交战；限时成功一次性获得稀有工坊冲锋枪（冲锋枪变体），超时或主动返回不阻断主路。

第三关寒镜水库使用双桥枢纽、泵站环路、岛状掩体和反射晶体岛。入口 → 双桥枢纽 → 北泵站 → 晶体岛 → 南泵站 → 水闸 → 补给 → 镜湖竞技场；枢纽另可先走南泵站，再回枢纽完成北侧。两处泵站均完成后才可通过水闸。北泵站另接商店，晶体岛另接供能机器人护送。

冰面只有轻微惯性，离开立即恢复普通牵引；闪避使用原距离，不受传送带/冰面放大。冰弹带短时轻微减速，侧翼游击者尝试从两侧接近。霜镜守卫有两段可见反射光束、冰环与锁定方向冰晶齐射，均先预警。护送限时 45 秒，靠近机器人 3 单位内才前进，途中两次伏击；机器人损毁或超时均失败，仍可退出继续主路。成功一次性恢复生命/能量。

## 商店与计时

两关商店均为可选安全支路。每关四个固定报价：治疗、能量、被动和特殊武器。显示实际价格、效果与金币；每件限购一次。购买先检查金币、资源上限与装备限制，失败不扣款，重复点击不重复发货；替换特殊武器仍使用原安全掉落流程。

浏览/购买暂停战斗、机关、冷却和限时任务，但属于主动决策，**关卡计时继续**。Esc 关闭商店。明确的暂停、地图、失焦、暂停设置及加载仍扣时，原因重叠只扣一次。三关共用毫秒量化和六种双语反馈，纪录按关卡稳定 ID 独立分组。

## 检查点与安全保存

`starfall-checkpoint.json` 与设置、个人纪录分开，位于 `Application.persistentDataPath`。版本 1，内容版本 `m3-v1`。包含本轮 ID、关卡编号、种子、金币、生命、武器槽、主动充能/冷却、被动层数与纪录资格；不保存场景对象、房间中途进度或临时护盾/训练辅助。

新冒险保存第一关入口；领取 Boss 奖励时，把**奖励后的状态与下一关入口作为一份完整检查点保存**。写入失败不发奖励，也不允许进入下一关，选择保留可重试。保存成功后可立即继续，也可退出后从下一关入口继续，不会重新领取上一关奖励。

关卡中途退出再继续，恢复该关原入场构筑、资源和种子，丢弃中途收益，本关计时从零，新尝试可按其原资格提交纪录。此前已合法保存的关卡纪录独立保留。教学、训练营、环境样本、重置或退出均不写检查点。

有检查点时“开始冒险”需确认替换；取消保留原进度。死亡及 M3 第三关完成写入失效标记，并使备份失效，不能从旧备份复活该轮。写入采用临时文件、落盘刷新和原子替换；损坏/不兼容文件保留并提示，必要时从备份恢复。全部磁盘写入都失败时不能保证失效标记持久化，界面会明确报错，应先修复权限/磁盘再使用该存档。

## 训练营与双语

环境区可免费启动真实传送带/热脉冲与冰面/水闸样本，停止、重置或退出会清理。默认训练无敌；可关闭辅助测试伤害。稀有冲锋枪变体也可免费试用。后续周期电网样本与剩余武器/主动/被动仍明确未实现。

新增商店、确认对话框、任务、Boss 动作、房间、存档提示均支持即时中英文切换。占位形状与程序音效沿用 M2b，M5 再完善美术和混音。

## 按顺序人工验收

1. 从 Boot/主菜单开始第一关，正常击败 Boss、三选一，再进入工坊；检查装备、资源和纪录保留。
2. 工坊清理两芯仓并取芯，试传送带与侧道、商店报价/满资源/重复购买，关闭炉体后击败三动作 Boss。可选生产线主动退出或超时不阻断主路。
3. 领取奖励后退出并关闭程序，再启动继续，应从第三关入口恢复同一种子、入场资源和构筑。中途取得收益再退出继续，收益不能保留，计时归零。
4. 水库尝试先南后北的环路、冰面和两泵任务；护送可成功、超时或主动退出；打开水闸并击败霜镜守卫，确认前三关各自纪录和 M3 停止点。
5. 有检查点时取消“新冒险”，原检查点应保留；进入教学/训练再返回，继续应不变。死亡后该轮不能继续，但此前个人纪录仍在。
6. 商店中检查计时继续；地图/暂停/失焦叠加时检查战斗与计时冻结。主要页面切换中英文，调音量/震屏/闪光设置，确认状态与纪录不变。
