# M4 · 六关冒险与完整装备

Unity 6000.6.4f1，Windows x64，键鼠。入口：`Assets/_Game/Scenes/Boot.unity`。已有资源已初始化，可直接打开场景后 Play；只有缺失 M4 配置时才执行 `Starfall > Setup M4`。工具重复执行保留已实现物品和原场景的手工参数，只升级原先未实现的条目。`Starfall > Validate M4 Assets` 检查入口、资源和双语。

普通 Windows 程序：`Builds/M4/StarcoreLabyrinth.exe`。保留相邻的 `StarcoreLabyrinth_Data`、DLL 与其他构建文件；不能只复制 exe。重新构建菜单：`Starfall > Build M4 Windows`。

## 主线与支路

开始冒险从第一关进入，第三关后现在可继续到第四、第五、第六关。每关 Boss 后选择一项成长，保存成功后进入下一关。最后一关将自身成绩和最终胜利显示在同一张卡上；死亡优先处理。各关纪录独立保存，后续死亡不会取消早期纪录。

| 关卡 | 主路任务 | 可选支路与主要规则 |
| --- | --- | --- |
| 幽孢温室 | 北、中央、南三处孢子巢；净化后关闭毒雾阀 | 环形岔路、可击碎菌丛、绿色安全岛、毒雾倒计时；连续净化最多三轮，轮间可主动结束。金币递增，第二轮受控增伤或能量，第三轮穿透弩。 |
| 雷轨中枢 | 依次关闭北、中央、南继电器；停用电网主控 | 十字枢纽、长轨与侧路；电网预警后脉冲，中央和外侧安全路线一直存在。电网支线坚持 18 秒后，可在三个工作站中领取一项补强。 |
| 星核圣所 | 关闭两道封印，再开启核心 | 较少普通敌人，轮换混合精英；最终准备室在免费全治疗和重选一种已有被动之间选择一次。星核守卫在约 67%/34% 生命转阶段，1 秒可见无敌后恢复。每次至多两种主要空间压力。 |

温室 Boss 使用藤蔓封路、有限召唤和孢子环；磁轨执法者使用轨道冲刺、电场分区和扇射；星核守卫使用弹幕、扇区封锁、扇射与末阶段冲刺。所有动作有预警和恢复窗口。召唤物和分裂子体不掉金币、不触发击杀回能，数量受上限控制。

## 武器与构筑

六类基础武器均已实现：手枪、霰弹枪、冲锋枪、蓄力穿透弩、延迟爆炸发射器、连锁电弧枪。稀有工坊冲锋枪作为额外变体保留。穿透弩按住左键蓄力后自动重复蓄力；发射器弹丸落点延迟爆炸；电弧首个命中后向邻近目标连锁，次级伤害标记来源并限制深度。

六种主动：急救包、短时护盾、减速场、击退震荡波、诱饵信标、爆破手雷。Q 使用，统一次数与冷却。满血治疗、闪避期间使用、次数不足和不可用落点均不扣资源。换装、换房、死亡和训练重置清理临时区域、诱饵与护盾。

十二种被动：射速、穿透、弹射、暴击、击杀回能、拾取范围、最大生命、闪避冷却、低生命防护、爆炸范围、受控增伤、无伤房间治疗。全部参数来自 `ItemCatalog.asset`，效果描述读取相同定义。每种最多两层、最多六种；第七种显示替换/放弃窗口。商店替换确认时重新校验金币并一次扣款，取消不扣款。

推荐实际测试的三套组合：穿透弩＋受控增伤＋减速场；霰弹枪＋闪避冷却＋护盾；电弧枪＋击杀回能＋诱饵。普通手枪和主路补给仍可完成正式流程，组合不是开门条件。

## 训练营

装备按武器、主动、被动分页；点击领取，说明展示稀有度和真实数值。选择被动后可移除一层；清空构筑用“恢复默认装备”。训练保留真实射速、蓄力、冷却、伤害、护甲与有效时间 DPS。无限能量、无限次数和无敌可分别切换，默认开启。

模拟区提供原有组合和各已实现普通敌人类型，存活上限 12。环境区提供真实传送带、冰面和周期电网样本。所有内容在普通构建中可用。训练与教学不写正式纪录、不替换主线检查点。

## 存档与计时

用户存档位置：`%USERPROFILE%/AppData/LocalLow/DefaultCompany/AI_Rogue_Game/`。设置、纪录、主线检查点分别保存，不提交到 Git。

检查点内容版本 `m4-v1`，入口快照包含构筑、资源、种子、资格和已完成阶段用时。兼容有效 `m3-v1` 的前三关入口；旧检查点缺少早期用时，最终卡明确标示部分累计，不能伪造全轮时间。继续从该关入口重开计时和目标，不保留关内收益。

奖励和下一入口先形成完整快照，磁盘写入成功才发放奖励；失败保持原快照并可重试。死亡或最终通关写入失效标记，设置与纪录保留。不可写磁盘会显示错误；所有磁盘写入都失败时，无法保证跨进程失效标记持久化。

计时版本仍为 `1`，平衡版本为 `2`，完整道具改变构筑规则。旧版纪录保留在“旧规则”分组，不与新版比较。菜单、地图、设置、失焦和加载不计时；商店决策计时。

## 人工验收顺序

1. 从 Boot 或普通 exe 进入教学，完成或跳过；切换语言后步骤与状态保持。
2. 进入训练营，分别领取六类武器、六种主动和十二种被动；试用三套组合、满六种替换/放弃、移除层数、重置和三个环境样本。
3. 开始主线，连续到第六关；温室净化三巢、中枢按序三继电器、圣所关闭两封印。主路无需随机钥匙或指定装备。
4. 试温室轮间结束、电网补强与最终准备室二选一；返回旧房不重复获得结算或支路奖励。
5. 暂停/地图/失焦、商店、返回菜单后继续入口；取消新冒险保留旧检查点。教学/训练再返回，继续仍恢复同一主线入口。
6. 检查最终卡与六关纪录，关闭程序后重开验证保留；另试死亡重开、满能量/空能量、同归于尽和存档错误提示。

详细自动验证结果、截图、日志及明确未验证项保存到外层 `appendix/M4/`。程序美术仍为已登记占位，正式美术与 25～40 分钟人工节奏调参属于 M5；1080p 性能、压力与 20 分钟持续运行属于 M6，未经实测不宣称通过。
