# M5 已实施的美术与界面规范

此文档记录当前实际配置。资源路径与许可见 [asset-guide.md](asset-guide.md)，稳定 ID 见 [asset-manifest.md](asset-manifest.md)。后续替换素材应先放进真实游戏查看。

## 造型和主题

精细手绘俯视 2D。主角为青绿披肩、暖金装备的人形探险者；小面积发光用于武器、信标和交互焦点。六主题分别采用苔绿遗庭、赤铜工坊、冰蓝水库、孢紫温室、电蓝中枢、象牙金圣所，地面、墙体、拱门和地标使用独立图像。

地面平铺，墙体分段，保持纹理比例。角色、交互物和危险高于普通装饰对比；实际碰撞及安全区由玩法配置决定，不从插画轮廓推断。

## 图片与动画

- Sprite：128 PPU、Bilinear、无 Mipmap、FullRect、非压缩，导入最大尺寸 4096。透明建筑和道具按 alpha 收紧切片，运行时保持纵横比。
- 主角：四向各四帧，行走 10 FPS，静止使用各方向首帧；按瞄准选择朝向。脚底 pivot 为 (0.5, 0.18)。受击染色、闪避倾斜/四个复用残影、死亡侧倒由表现代码驱动。
- 普通敌人和 Boss：脚底 pivot 为 (0.5, 0.2)，叠加轻微起伏、接触阴影和受击表现；专用炮台、无人机和孢体使用补充图集。
- 玩家/敌人按 Y 坐标排序，枪随朝向切换前后层级；枪口从身体到枪口做墙体检查。七种持枪图与实际武器 ID 同步，不把单张矩形染色当作武器切换。
- 地面：六张 512×512 模块，约 4 世界单位平铺；墙体约每 2 世界单位分段。props 图集按实际不等高行切片，不能改成均匀三行而切入邻格。
- 76 个视觉 Prefab 与碰撞/玩法分开，PresentationCatalog 显式引用并实际实例化；后续 Setup 保留已存在 Prefab 内容。

## 光影与反馈

世界使用 Sprite Lit、约 0.9 强度主题环境光、三个有可见发光物对应的局部光、角色接触阴影和掩体 ShadowCaster。实际游戏相机启用 HDR 与 Volume；默认 Profile 包含克制的 Bloom、色彩调整、色调映射及 0.08 暗角，精简 Profile 减弱效果。HUD 使用 Overlay Canvas，不进入世界后期。

拾取卡最多三个、补给消息合并；伤害数字池有界并合并近似命中。伤害、暴击、失败拾取来自真实结果。设置保留简洁效果、震屏 0、减弱闪光、暗角和数字开关；不要靠增加全屏闪白表达强度。

## 字体与页面

标题使用思源宋体 SemiBold，正文思源黑体 Regular，强调 Medium。三个 TMP 动态 SDF 字库为 42 点、2048 多图集、6 padding、SDFAA，预热双语文字；源 OTF、中文断行和许可随发布提供。正文最小 16，不依赖 Windows 安装字体。

深青面板、象牙正文、青绿选中态、暖金奖励。主菜单/选关/整备/商店/比较/训练/设置/结算/纪录共用字族和图标。宽屏六张卡使用 3×2，4:3 使用 2×3；详情与开始按钮固定。1280×720、1920×1080、2560×1440、1280×960 均进行双语实际渲染检查。

E 只领取物品，F 只操作设施；模态暂停世界输入和计时，退出要求松键后再触发。Esc 每次返回一层并恢复焦点。世界美术不承载按键文字，提示由双语 UI 生成。

## 替换与验证

保留稳定 ID、`.meta`、源稿与许可。修改图集后运行 Setup/Validate，并检查脚底、裁切、枪口、排序和普通构建。更新机器清单可运行 `Tools/M5Manifest.py`；该工具只读取资源，不修改图像。

截图能验证导入和排版；真人审美、动态手感、危险可读性及扬声器/耳机听感由实际体验确认，性能另在 M6 测量。
